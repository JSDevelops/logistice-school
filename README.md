# Logistice School - VEF Group Website

เว็บไซต์โรงเรียนโลจิสติกส์ บริษัท วีอีเอฟ กรุ๊ป จำกัด (VEF Group)

## หน้าเว็บไซต์

| หน้า | ไฟล์ | คำอธิบาย |
|---|---|---|
| หน้าหลัก | `index.html` | Hero Slider, บริการ, ผลงาน |
| เกี่ยวกับเรา | `about.html` | วิสัยทัศน์, จุดแข็ง |
| บริการ | `service.html` | หลักสูตร 8 รายการ |
| ติดต่อเรา | `contact.html` | ฟอร์ม, แผนที่ |

## เทคโนโลยี

- HTML5 + Vanilla CSS (Modern Minimal Design)
- Font: Prompt (Google Fonts)
- สีหลัก: `#0f0a5e` (Navy) + `#00c9c8` (Teal)
- ไม่ใช้ Framework ภายนอก — โหลดเร็ว ใช้งานง่าย

## โครงสร้าง

```
logistice-school/
├── index.html
├── about.html
├── service.html
├── contact.html
├── assets/
│   └── css/
│       └── main.css
├── Home_files/         # รูปภาพและ assets หน้าหลัก
├── About us_files/     # รูปภาพหน้าเกี่ยวกับเรา
├── Service_files/      # รูปภาพหน้าบริการ
└── Contact us_files/   # รูปภาพและแผนที่หน้าติดต่อ
```

## การใช้งาน

เปิด `index.html` ด้วยบราวเซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม
